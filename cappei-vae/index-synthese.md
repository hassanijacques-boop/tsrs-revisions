## Articulation des 3 actions

Ces 3 actions ne sont pas indépendantes : elles forment un **système cohérent** :

```
                    ┌──────────────────────┐
                    │   ALTius PPRE (DC1)   │
                    │   (Outil socle qui    │
                    │   structure les PPRE  │
                    │   et outille l'équipe)│
                    └──────────┬───────────┘
                               │
              ┌────────────────┼────────────────┐
              │                │                │
              ▼                ▼                ▼
   ┌────────────────┐  ┌──────────────┐  ┌──────────────┐
   │  Fiche 3 (DC2) │  │ Fiche 2 (DC4)│  │              │
   │  Protocole     │◄─┤Défi Éloquence├─►│  AESH,       │
   │  Fluence       │  │(passerelle   │  │  collègues   │
   │  (ma classe)   │  │ CM2/Collège) │  │  formés      │
   └────────────────┘  └──────────────┘  └──────────────┘
```

- **Fiche 3** utilise les parcours (Vert/Orange/Rouge) générés par l'outil Altius PPRE
- **Fiche 2** réutilise les données de fluence de la Fiche 3 comme outil de diagnostic pour la liaison CM2/6ème
- **Fiche 1** fournit le cadre méthodologique (fiches de route AESH, micro-objectifs) qui rend possible la différenciation en classe (Fiche 3) et la transmission au collège (Fiche 2)
